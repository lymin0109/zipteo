# GitHub Pages 에 올리기

인터넷에 공개해서 남에게 링크로 보여주는 방법입니다. **무료이고 15분이면 됩니다.**

이 폴더 안의 파일만 올리면 됩니다. 파이프라인 스크립트(`config.py` 등)는 **절대 올리지 마세요.**

```
index.html        첫 화면
app.html          추천 앱 (데이터가 안에 들어 있어 단독으로 동작)
map.html          카카오맵 뷰 (키 입력 필요)
data/apts.js      단지 데이터
.nojekyll         GitHub 이 파일을 건드리지 않게 하는 표시 (빈 파일)
```

---

## 0. 먼저 — 카카오 키 한 줄 넣기

`map.html` 을 메모장으로 열면 위쪽에 이 줄이 있습니다.

```js
const KAKAO_JS_KEY = "여기에_JavaScript_키";
```

따옴표 안을 **JavaScript 키**로 바꾸세요. developers.kakao.com → 내 애플리케이션 → 앱 키.

> ⚠️ **REST API 키가 아닙니다.** 그리고 ODsay·공공데이터포털 키는 여기 넣을 일이 없습니다.
> JavaScript 키는 페이지 소스에 그대로 보이는 게 정상입니다 — 대신 아래 4단계의
> **도메인 등록이 유일한 방어선**이니 꼭 하세요.

카카오맵을 안 쓰실 거면 `map.html` 을 지우고 `index.html` 에서 그 카드를 지우셔도 됩니다.

---

## 1. GitHub 계정 만들기

`github.com` → Sign up. 이메일과 비밀번호만 있으면 됩니다.

---

## 2. 저장소 만들기

오른쪽 위 **+ → New repository**

| 항목 | 입력 |
|---|---|
| Repository name | `jipteo` (원하는 이름) |
| 공개 설정 | **Public** |
| Add a README | 체크하지 마세요 |

> 무료 계정은 **Public 저장소만** Pages 를 쓸 수 있습니다.
> 즉 이 폴더의 파일은 누구나 볼 수 있게 됩니다. 실거래가는 공공데이터라 문제없지만,
> 개인적인 메모나 키 파일이 섞이지 않았는지 한 번 더 확인하세요.

---

## 3. 파일 올리기

만들어진 저장소 화면에서 **uploading an existing file** 을 누르고,
이 폴더 안의 파일을 **통째로 끌어다 놓으세요.**

- `data` 폴더도 폴더째로 끌어다 놓으면 구조가 유지됩니다.
- `.nojekyll` 은 파일 탐색기에서 숨김 처리될 수 있습니다.
  안 보이면 **보기 → 숨긴 항목** 을 켜세요. (없어도 대개는 동작합니다.)

아래 **Commit changes** 를 누르면 업로드가 끝납니다.

---

## 4. Pages 켜기

저장소 → **Settings** → 왼쪽 메뉴 **Pages**

| 항목 | 선택 |
|---|---|
| Source | Deploy from a branch |
| Branch | `main` / `/ (root)` |

**Save** 를 누르고 1~2분 기다리면 같은 화면 위쪽에 주소가 뜹니다.

```
https://<본인아이디>.github.io/jipteo/
```

이 주소가 링크로 보내실 주소입니다.

---

## 5. 카카오에 그 주소 등록 (지도를 쓰신다면)

developers.kakao.com → 내 애플리케이션 → **앱 설정 → 플랫폼 → Web → 사이트 도메인 등록**

```
https://<본인아이디>.github.io
```

> 경로(`/jipteo`)는 빼고 **도메인만** 넣습니다.
> 이걸 안 하면 키가 맞아도 지도가 안 뜹니다. `localhost:8000` 은 그대로 두셔도 됩니다.

---

## 데이터를 새로 뽑았을 때

`build_dataset.py --emit` 으로 새 `apts.js` 를 만드셨다면 두 군데를 갱신해야 합니다.

1. **`data/apts.js`** — 저장소에서 그 파일을 열고 연필 아이콘 → 내용 교체, 또는 그냥 같은 이름으로 다시 업로드
2. **`app.html`** — 이 파일은 데이터를 **안에 품고** 있습니다. 새 데이터를 반영하려면
   `app.html` 에서 `const RAW = [` 로 시작하는 줄부터 그 배열이 끝나는 `];` 줄까지를
   새 `apts.js` 의 같은 블록으로 통째로 교체하세요.

2번이 번거로우면 저에게 새 `apts.js` 를 주세요. 갱신한 `app.html` 을 만들어 드리겠습니다.

---

## 막히면

- 주소를 열었는데 404 → Pages 설정에서 Branch 가 `main` / `root` 인지 확인, 2분 더 기다려 보세요.
- 지도만 안 뜬다 → 4단계 도메인 등록, 그리고 브라우저 **F12 → Console** 의 빨간 줄을 확인하세요.
- 앱은 뜨는데 단지가 5곳뿐 → `data/apts.js` 가 안 올라갔거나 경로가 다릅니다.
